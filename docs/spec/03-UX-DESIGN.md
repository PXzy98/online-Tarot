# 03 · UX 与视觉设计

## 1. 视觉方向

**Modern Mystical / Celestial Minimalism**：克制、安静，有仪式感，但不廉价。品牌名“静观”就是设计基调：留白多、动效慢而少、没有闪烁。

避免：满屏星光粒子、廉价渐变、大量闪烁、影响阅读的艺术字体、模板站观感。

## 2. 设计 Token（初始值，需通过对比度验证）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#101321` | 主背景 |
| `--bg-elevated` | `#1A1B2E` | 卡片、面板 |
| `--fg` | `#F3EDE2` | 主文本 |
| `--fg-muted` | 低饱和灰紫（P1 确定，对 `--bg` 对比度 ≥ 4.5:1） | 次要文本 |
| `--accent` | `#D8BB82` | 强调、焦点环 |
| `--accent-deep` | `#68517F` | 装饰（不用于承载文字） |
| `--focus` | 由 `--accent` 派生 | 焦点环 ≥ 3:1 |

- v1 只做深色主题，Token 结构要预留浅色主题。
- 所有文字和背景的组合都要用工具校验，达到 WCAG 2.2 AA。

## 3. 排版

- 字体方案见 02 §11。
- 字号层级：移动端正文 16px、行高 1.7（中文）/ 1.6（英文）；桌面端正文 17–18px。
- 解读正文的最大行宽：中文约 36 字，英文约 70 字符。
- 英文标题可以使用衬线体营造仪式感；正文永远优先清晰易读。

## 4. 卡牌组件 `<TarotCard>`

状态：`back`（背面）· `face`（正面）· `selectable`（可选）· `selected`（已选）· `disabled`（不可选）· `flipping`（翻转中）· `reversed`（逆位）。

- 固定比例（RWS 约为 11:19，以实际素材为准），用 `aspect-ratio` 锁定，不允许拉伸。
- 逆位通过牌面旋转 180° 表示，同时**必须**配有文字标记“逆位 / Reversed”，`aria-label` 中也要写明。
- 可聚焦：焦点环清晰；`Enter` / `Space` 触发。
- 名称、位置、正逆位都以文字形式出现在牌的下方或 aria 信息中，不能只靠图像传达。

## 5. 选牌交互：78 张全部可选（必须完整）

用户必须能在全部 78 张牌中自由选择，不允许缩减成一个子集。

### 5.1 布局

- **移动端默认：横向滑动牌带**。一排（屏幕高度足够时两排）牌背，`overflow-x: auto` 加 `scroll-snap`，牌有轻微重叠，每张可点击区域 ≥ 44×44 CSS px。
- **切换为“网格视图”**：纵向滚动，手机 6 列、平板 9 列、桌面 13 列，78 张全部铺开。视图切换按钮始终可见，选择写入偏好。
- **桌面端默认**：完整铺开的弧形或多行扇形，78 张一屏内可见；窗口太窄时自动退回牌带或网格。
- 牌带两端有渐隐提示，并显示“滑动查看全部 78 张”的提示（首次显示一次）。
- 一个固定的进度条显示“已选 1 / 3”和各位置的槽位。点击已填充的槽位可以撤回（在开始翻牌之前）。

### 5.2 防误触

- 横向滑动时不触发选牌：只有位移 < 10px 的点按才算选择。
- 选中后的牌会飞向槽位，原位置变为不可选，并在视觉上标记为已取走。
- 动画进行中把输入排队或忽略，由状态机保证幂等。

### 5.3 无障碍与快捷方式

- 牌带 / 网格使用 roving tabindex：方向键移动，`Home` / `End` 跳到两端，`Enter` 选择。
- 每张牌的读屏文本：“第 12 张，共 78 张，未选择”。选择后通过 `aria-live` 播报“已放入‘现在’位置，还需选择 1 张”。
- **“替我抽牌”按钮**：随机补齐剩余位置，让完成占卜不依赖精细的触控或动画。

## 6. 动画（motion）

| 场景 | 时长 | Reduced Motion 下 |
|---|---|---|
| 洗牌 | ≤ 2.5s，可跳过 | 0.3s 淡入淡出 |
| 选牌飞入槽位 | 0.35s | 直接出现 |
| 翻牌 | 每张 0.6s，依次进行，可“全部翻开” | 淡入淡出 |
| 结果段落进入 | 每段 0.2s 依次进入 | 无 |
| 页面过渡 | 0.2s 淡入 | 无 |

- 遵循 `prefers-reduced-motion`，偏好中可以设为“跟随系统 / 开 / 关”。
- 动画只是表现层：跳过、中断或在后台标签页暂停时，最终状态都由状态机决定。
- 不使用无限循环的高开销动画。只对 `transform` / `opacity` 做动画。
- 交互页面才加载 motion：在百科、详情等内容页中，用动态导入或 CSS 过渡代替。

## 7. 响应式断点

覆盖：小屏手机（360×640）、普通手机（390×844）、平板（768×1024）、笔记本（1280×800）、宽屏（1920×1080）。

Mobile-first。三张牌的牌阵在 360px 宽度下：三个槽位并排，每张宽度 ≥ 96px，或改为纵向排列，不能出现水平溢出。所有固定在底部的操作栏都要避开 `safe-area-inset-bottom`。

## 8. 结果页结构

1. 问题（如果有）、牌阵、日期
2. 牌阵图：各位置的牌和正逆位
3. **总述**（summary）
4. 逐张解读：位置 → 牌名 + 正逆位 → 关键词 → 结合位置和问题类型的解释
5. **牌之间的联系**：每句话都可以展开查看“依据”（例如“元素关系：火与水，传统元素尊贵法”）
6. 建议（列表）
7. 反思问题（列表）
8. 操作：保存到历史（可勾选“同时保存问题”）· 复制摘要 · 生成分享图 · 复制为 AI 提示词 · 新的占卜
9. 页脚处一行赞助链接（静态文字链接，不弹窗）

## 9. 无障碍（WCAG 2.2 AA）

语义化地标 · 跳转到主内容链接 · 合理的焦点顺序与可见焦点 · 对比度达标 · 所有交互支持键盘 · 状态变化通过 `aria-live` 播报 · 不依赖动画或颜色传达信息 · 表单有关联的 label 和错误提示 · 语言切换后 `<html lang>` 正确 · 触控目标 ≥ 24×24（主要操作 ≥ 44×44）。
