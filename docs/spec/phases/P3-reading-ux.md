# P3 · 占卜交互

**先读**：00-README、01-PRODUCT §3、§5–6、03-UX-DESIGN（全部）、02 §7–8

## 目标

用户可以从首页开始，完成一次完整的占卜（洗牌 → 从 78 张中选牌 → 翻牌 → 进入结果页），手机和桌面都可用。

## 范围

- 首页（品牌、主视觉、开始占卜、每日一牌、牌阵和百科入口、三步流程说明）。
- `/reading/`：问题类型、问题输入（500 字符限制和计数）、牌阵选择、洗牌动画、选牌（**78 张全量**：牌带、网格、桌面扇形；防误触；撤回；替我抽牌）、翻牌（逐张翻开或全部翻开）。
- `<TarotCard>`、`<CardImage>`、牌面包接口，并接入 `still-minimal` 原创 SVG 牌面（如果 `rws-1909` 素材已核实完成，也可以同时接入）。
- 刷新后恢复草稿；选牌中途切换语言时进度保留。
- Reduced Motion、跳过动画、键盘操作、aria-live 播报。
- `/reading/result/?id=`：结果页框架，包含牌阵图和逐张牌位（解读部分留给 P4 填充，此时显示“牌名 + 位置 + 正逆位”，并且只在开发模式下出现开发提示）；空状态。
- 设置：仅正位、动画偏好。

## 验收

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm e2e
```

E2E 至少覆盖 08 §5 的第 1、2、3、7、8、9、10、13 项（解读相关的断言除外）。另外提供 360px、390px 和 1280px 宽度下的截图，作为布局证据。
