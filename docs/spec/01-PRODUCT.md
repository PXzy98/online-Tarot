# 01 · 产品

## 1. 名称与定位

- 中文名：**静观**（页面标题等场景可用「静观塔罗」）
- 英文名：**Still Tarot**（"Still" 兼有“静止”与“依然”的意思）
- 定位：一个安静、克制、完全免费的塔罗网站。对外只用一句话说明性质：“塔罗解读仅供娱乐参考，不构成医疗、法律、财务或其他专业建议。”不额外声明“不做预言”之类的话。

## 2. 核心原则

- 所有功能永久免费，不设付费功能、点数、订阅或次数限制。
- 不要求注册，不收集姓名、邮箱、手机号。
- 核心功能全部在浏览器内完成，不依赖数据库、后端或付费 AI。
- 用户的问题和历史只存在本机，不上传。
- **自愿赞助**：页面上提供 Patreon 链接和支付宝收款码（见 07-COMPLIANCE §5）。赞助不解锁任何功能，不在占卜流程中弹出打扰。
- **部署成本尽可能低**：纯静态托管，目标是除域名外零运营成本（见 02-ARCHITECTURE §9）。
- **多语言从第一天起**：界面带语言切换，首发支持 `zh` 和 `en`，新增语言不需要改核心代码。

## 3. 核心流程

```
（可选）选择问题类型 / 输入问题 → 选择牌阵 → 洗牌 → 从 78 张牌中选牌 → 翻牌 → 查看解读 → 保存 / 复制 / 分享
```

用户可以跳过问题，直接自由占卜。所有动画都可以跳过。

## 4. 塔罗体系

- Rider–Waite–Smith（RWS），78 张：22 张大阿尔卡那（0 The Fool … XXI The World，RWS 顺序：Strength = VIII，Justice = XI），以及 56 张小阿尔卡那（Wands / Cups / Swords / Pentacles，每组 Ace、2–10、Page、Knight、Queen、King）。
- 正逆位：默认各 50%，独立随机。设置中提供“仅使用正位”开关（v1 就做）。
- 第一版牌阵：
  - **单张牌**：每日指引、简单问题。
  - **过去 — 现在 — 未来**：强调发展脉络，“未来”表述为“延续当前趋势的可能方向”，不是确定事实。
  - **现状 — 障碍 — 建议**：重点分析障碍与建议之间的关系。
- 预留但不实现：凯尔特十字、关系牌阵、决策牌阵、事业牌阵、马蹄牌阵、自定义牌阵。

## 5. 问题类型

`general` 综合 · `love` 感情 · `career` 事业 · `study` 学业 · `relationships` 人际关系 · `growth` 个人成长

- 不设财务类型。问题文本中涉及财务、医疗、法律等内容时，由安全层追加提示（07-COMPLIANCE §4）。
- 自定义问题最多 500 个 Unicode 字符（按 grapheme 计数），只以纯文本渲染。

## 6. 页面清单

所有页面都位于 `/{locale}/` 之下（如 `/zh/cards/`、`/en/cards/`），根路径 `/` 是语言分流页。

| 路径 | 说明 | 是否收录 |
|---|---|---|
| `/` | 语言分流：已保存的偏好 → 浏览器语言 → 默认 `zh`；不支持 JS 时显示语言链接 | 是（x-default） |
| `/{l}/` | 首页：品牌、主视觉、简介、开始占卜、每日一牌、牌阵、百科入口、三步流程说明 | 是 |
| `/{l}/reading/` | 分步占卜流程 | 是（流程页本身不含私人数据） |
| `/{l}/reading/result/?id=…` | 结果页；从本地记录加载，无记录时显示空状态 | **noindex** |
| `/{l}/daily/` | 每日一牌（个人随机，按本地日期固定） | noindex |
| `/{l}/cards/` | 卡牌百科：分类、花色筛选、中英文名称搜索 | 是 |
| `/{l}/cards/{slug}/` | 78 张牌的详情页，构建时静态生成 | 是 |
| `/{l}/spreads/` | 牌阵介绍 | 是 |
| `/{l}/history/` | 本地历史：查看、删除、清空、导入导出 JSON | **noindex** |
| `/{l}/guide/` | 塔罗入门指南 | 是 |
| `/{l}/about/` | 关于 | 是 |
| `/{l}/privacy/` | 隐私说明 | 是 |
| `/{l}/support/` | 赞助页（Patreon、支付宝收款码等） | 是 |
| 404 | 友好的 404，带返回链接 | — |

页脚包含：关于、隐私、指南、赞助、语言切换，以及一句简短的免责声明。

## 7. 每日一牌

- **个人随机**：用户在本地日期当天第一次打开 `/daily/` 时，用安全随机生成一张牌及其正逆位，保存在本机。
- 当天再次访问（包括刷新、切换语言）显示同一结果。日期按设备本地时区计算；页面一直开着跨过午夜时，在 `visibilitychange` 或聚焦时重新检查日期。
- 清除浏览器存储后会重新抽牌，不同设备之间不共享。这些行为都在页面上简短说明。
- 不影响普通占卜的使用。

## 8. 内容边界

- 不预测死亡或疾病，不对投资、医疗、法律给出确定性结论。
- 不用恐惧或紧迫感诱导用户行动。
- 不伪装成 AI 功能。
- 免责声明只出现在页脚（每个页面都有），不反复打断操作。

## 9. 明确不做的事（v1）

付费功能、充值、点数、会员、站内支付 SDK（Stripe 等）、强制登录、真人预约、社区、实时多人、商城、广告、依赖付费 AI 的核心解读、数据库、微服务。

> 赞助只是**外部链接加一张静态二维码图片**，不属于站内支付系统。

## 10. 可选的 AI 扩展点（v1 只做零成本部分）

- **“复制为 AI 提示词”**：把牌阵、牌面和位置（问题需用户勾选才包含）生成一段文本，用户可以自行粘贴到任意 AI 助手。不调用任何 API，没有成本，也没有隐私风险。
- 解读引擎通过 `InterpretationProvider` 接口实现，将来可以接入其他实现（见 04 §9），v1 只有基于规则的实现。
